How the Agent Works

01 DISCOVER
Reads The Task
Receives a plain-English work order, checks available skills, and discovers supported Kite services when the task needs outside tools.
02 SETTLE
Settles Payment
Uses an Agent Session key, x402 where supported, or one-time Kite tx proof before protected work executes.
03 WORK
Runs Live Skills
Routes the prompt to market intelligence, research, writing, receipts, code review, travel, shopping briefs, or Kite service discovery.
04 ATTEST
Publishes Proof
Every decision or work order gets an attestation hash. Kite tx hashes remain the public settlement reference.
